- $((  ))
This is a bash construct. Within those walls, MATHS can be performed.
I.e. <green>$(( 1+1 )) = 2</green>

- fastfetch
Command to show system information and the <red>lovely</red> splash-screen.
The original version was called neofetch, however neofetch was abandoned (and was a bash script 😔).
fastfetch is written in C by Linus Dierheimer.
